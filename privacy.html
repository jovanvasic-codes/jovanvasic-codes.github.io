Privacy Policy

Meanwhile Elsewhere Uploader

Effective date: October 5, 2026

Who we are

"Meanwhile Elsewhere Uploader" is a private tool run by Jovan Vasić (Serbia), the owner of the YouTube channel "Meanwhile, Elsewhere". Contact: jovan.vasic01@gmail.com.

What the tool does

The tool uploads videos that were made for the "Meanwhile, Elsewhere" channel to that channel, and sets each video's title, description, tags, category and publication time. It is used only by the channel owner, for his own channel. It is not offered to anyone else.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • Only the channel owner's own Google account authorizes the tool, with a single permission: youtube.upload (upload and manage videos on that channel).
  • The tool does not read, collect or store data about viewers, subscribers or any other user.
  • The tool uses no cookies, no analytics and no advertising identifiers.

How the data is stored and shared

The authorization token is stored only on the channel owner's own computer. It is never sold, shared or transferred to anyone, and it is used only to upload the owner's videos.

How to revoke access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Revoking it makes the stored token useless; it is then deleted.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no tracking. GitHub may log technical data such as IP addresses, as described in the GitHub Privacy Statement.

Changes

Any change to this policy will be published on this page with a new effective date.
