Privacy Policy

Meanwhile Elsewhere Studio

Effective date: October 5, 2026

Who we are

"Meanwhile Elsewhere Studio" is a private tool run by Jovan Vasić (Serbia), the owner of the YouTube channel "Meanwhile, Elsewhere". Contact: jovan.vasic01@gmail.com. It is used only by the channel owner, for his own channel, and is not offered to anyone else. Uploading new videos is done by a separate tool, the Meanwhile Elsewhere Uploader.

What the tool does

  • Reads the channel's own statistics (views, watch time, audience retention, traffic sources, subscribers and, once the channel is monetized, revenue reports) to learn which videos work and to plan new ones.
  • Reads comments on the channel's own videos so the owner can learn from viewers' feedback.
  • On the owner's instruction only, manages the owner's own videos: updates titles, descriptions and translations, adds captions and thumbnails, organizes playlists, and replies to or moderates comments.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • Only the channel owner's own Google account authorizes the tool, with these permissions: youtube.force-ssl (manage the owner's own videos, playlists, captions and comments), yt-analytics.readonly and yt-analytics-monetary.readonly (the channel's own reports).
  • The reports are aggregated statistics about the channel and its videos. The tool does not collect personal data about viewers; public comments on the channel's videos are read to learn from feedback.
  • The tool uses no cookies, no analytics of its own and no advertising identifiers.

How the data is stored and shared

The authorization token is stored only on the channel owner's own computer. Statistics about the channel are kept privately, on that computer and in the owner's private code repository, to follow the channel's performance over time. Nothing is sold, shared or transferred to anyone.

How to revoke access and delete data

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Revoking it makes the stored token useless; the token and the stored YouTube data are then deleted within 7 days. To ask for deletion, write to jovan.vasic01@gmail.com.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no tracking. GitHub may log technical data such as IP addresses, as described in the GitHub Privacy Statement.

Changes

Any change to this policy will be published on this page with a new effective date.
